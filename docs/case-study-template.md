# 事例掲載用 入力ひな型（管理者向け・非公開）

> 公開サイトに実際の事例を載せる際の入力用テンプレートです。
> 各項目は確認できる事実のみを記入し、不明な項目は空欄のまま残してください（空欄の項目は公開文に含めません）。
> 効果の数値は、測定条件とあわせて記入してください。測定条件が確認できない数値は公開しません。
